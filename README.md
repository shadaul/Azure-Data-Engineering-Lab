About This Project

This is my hands-on lab where I built a data engineering infrastructure in Microsoft Azure from scratch. I'm actively expanding my tech stack and focusing on cloud engineering, so my goal here was to go beyond the UI basics: I automated the deployment, set up real-time streaming, and built batch ETL pipelines.
Tech Stack

    Azure Synapse Analytics (Pipelines, SQL pools, Spark)
    Azure Data Lake Storage Gen2
    Azure Stream Analytics
    PowerShell (Infrastructure as Code)

What I Built

    Infrastructure as Code (IaC): Used PowerShell scripts to automatically provision the Synapse workspace and analytics pools instead of clicking through the portal.
    Real-time Streaming: Configured an Azure Stream Analytics job to capture live data feeds and persist them directly into the Data Lake.
    ETL Pipelines: Built automated data ingestion pipelines in Synapse Studio to pull external datasets via HTTP APIs into the storage containers.
